# Predi-o-de-Pesos-e-Comportamentos-partir-de-vis-o-computacional
Projeto de Pesquisa desenvolvido por universitários da Faculdade Federal de Mato Grosso de Cuiabá (UFMT). O qual utiliza visão computacional 3d para predição de pesos em animais bovinos. Desenvolvido pelos alunos: Guilherme Emanuel Ferreira Ferraz e Reinaldo, ambos do curso de Engenharia de Controle e Automação da UFMT
